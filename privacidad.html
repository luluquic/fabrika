Privacy policy

Fabrika · Last updated: October 1, 2026

Fabrika is a private desktop tool used only by its owner, Luis Carlos Delgado, to produce videos and upload them to YouTube channels he owns. This policy explains what data Fabrika accesses and how it is handled.

Use of YouTube API Services

Fabrika uses YouTube API Services. By using Fabrika you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data Fabrika accesses

  • The basic identity of the authorized YouTube channel (channel ID and name), to confirm uploads go to the right channel.
  • Permission to upload videos, thumbnails and captions, set titles, descriptions, tags and privacy status, and add videos to playlists on that channel.

Fabrika does not read viewers' personal data, comments, messages, analytics or payment information.

How the data is used

Data is used only to upload and organize the owner's own videos on the owner's own channels. It is not used for advertising, profiling, or any other purpose.

Storage and sharing

  • The authorization token is stored only on the owner's computer, in a file with restricted permissions. There is no Fabrika server or database.
  • No data is sold, rented, or shared with third parties.
  • Fabrika's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions. Revoking access makes the stored token useless; the owner can also delete the token file from his computer at any time. Fabrika keeps no other copy.

Contact

Questions about this policy: delgado.luisc@gmail.com

Política de privacidad

Fabrika es una herramienta privada que usa solo su dueño, Luis Carlos Delgado, para subir videos a sus propios canales de YouTube mediante los Servicios de API de YouTube. Al usar Fabrika se aceptan las Condiciones del Servicio de YouTube y aplica la Política de Privacidad de Google.

  • Accede solo a la identidad del canal autorizado y al permiso para subir y editar sus propios videos.
  • El permiso (token) se guarda solo en la computadora del dueño. No hay servidor ni base de datos, y no se comparten ni venden datos.
  • Cumple la Política de Datos de Usuario de los Servicios de API de Google, incluido el uso limitado.
  • El acceso se puede retirar en cualquier momento en security.google.com/settings/security/permissions.
